## 実装済み

- Java 21固定、Spring Boot 4.1.1、Maven Wrapper 3.9.11
- Spring MVC、Thymeleaf、Spring Security、Spring Data JPA、Flyway、Actuator
- PostgreSQL 17向け `V1__create_expenseflow_schema.sql`
  - `departments`
  - `users`
  - `expense_requests`
  - `expense_events`
  - 外部キー、CHECK制約、楽観ロック用version、検索・履歴索引
- フォームログイン `/login`
- POSTログアウト `/logout`
- CSRF保護を有効化。ログインフォームとログアウトフォームにトークンを埋め込み済み。
- 未認証時の保護ページからログイン画面へのリダイレクト
- 日本語ログイン画面、共通ヘッダー、CSS
- `/expenses` はフェーズ1の未実装範囲を明示する案内画面
- `demo` プロファイル限定の架空データ
  - 営業部・開発部の社員および承認者を含む5ユーザー
  - 認証用の固定値はソースとテストにのみ定義し、引き継ぎ文書には記載しない
- `compose.yaml`、`Dockerfile`、`.env.example`、GitHub Actions CI
- Testcontainers PostgreSQL + MockMvcのT01/T12テスト
- Spring Boot 4.1.1向けのFlyway・MVCテスト依存関係とTestcontainers 2.x成果物名を修正
- 通常プロファイルのデモデータ不在、demoプロファイルの冪等性、Flyway適用、ログイン・CSRF・ログアウトをTestcontainersで検証
- GitHub Actionsで`test`、`verify`、Compose設定、demoログイン／ログアウト、DB永続化を検証
