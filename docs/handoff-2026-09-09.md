## 未完了・最優先

1. Java 21を用意する。現在の環境はJava 17.0.19。
2. Dockerを用意・起動する。現在はDocker CLIがない。
3. `./mvnw --batch-mode test` を実行する。
4. 失敗があればJava 21/Spring Boot 4.1.1のAPI差分を原因確認して修正する。仕様を緩めるためにJavaバージョン、CSRF、Testcontainers、PostgreSQLを変更しない。
5. `./mvnw --batch-mode verify` を実行する。
6. `docker compose config` を実行する。
7. `.env.example` から `.env` を作り、`SPRING_PROFILES_ACTIVE=demo docker compose up --build` で起動確認する。
8. `/login` でデモ社員としてログインし、ログアウトがPOSTであることを確認する。
9. 実行日・コマンド・結果・未実行項目を `docs/test-results.md` に追記する。
10. その後、`docs/progress.md` を更新してからフェーズ2に進む。

## Git・クラウド継続

現時点ではローカルGitにリモートが設定されていません。リモートURLを勝手に推測せず、ユーザーから指定を受けて次を実行します。

```bash
git remote add origin <指定されたリモートURL>
git push -u origin main
```

この初回コミットは、フェーズ1の実装途中状態です。クラウド作業では、未実行検証を済ませるまでフェーズ1完了と報告しないでください。

## 注意事項

- 通常プロファイルではデモユーザーを自動生成しない。
- パスワードをログに出さない。
- CSRFを無効化しない。
- Java 17へ設定を下げて成功扱いにしない。
- Dockerが使えない場合、Testcontainersテストをスキップ・無効化せず、未実行理由として報告する。
- 申請・承認機能はまだ実装していない。未接続のボタンやダミー成功レスポンスを追加しない。
